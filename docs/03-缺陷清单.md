# 缺陷清单

站点是练习站，下面两个问题我故意没有改，用来练“发现问题后怎么记录、怎么让用例稳定地挂在缺陷上”。两条都写成了 `xfail`，跑全量时会显示 `x`，不会假装通过。

## SHOP-01 购物车不校验库存

- **严重程度**：中
- **复现步骤**：
  1. 用 `student@example.com` 登录。
  2. 打开 iPhone 17 Pro 详情，库存显示 12。
  3. 在详情页数量填 13，点加入购物车。
  4. 打开购物车，数量是 13，合计 116987.00。
  5. 点去结算，订单也能提交。
- **期望**：加购或结算时提示库存不足，最多只能买 12 台。
- **实际**：加购和结算都不拦，订单能创建。
- **影响**：库存会被超卖，支付后库存按 `max(0, stock - qty)` 扣成 0。
- **用例**：`tests/test_cart.py::test_cart_rejects_quantity_above_stock`
- **状态**：未改，`xfail`

## SHOP-02 登录邮箱区分大小写

- **严重程度**：低
- **复现步骤**：
  1. 打开登录页。
  2. 邮箱输入 `Student@example.com`，密码 `Shop@123`。
  3. 点登录。
- **期望**：邮箱不区分大小写，能正常登录。
- **实际**：提示“邮箱或密码不对”，留在登录页。
- **影响**：用户首字母大写时登不进去，体验不好。
- **用例**：`tests/test_login.py::test_login_email_case_insensitive`
- **状态**：未改，`xfail`

## 附：排查过但不是站点缺陷的问题

跑全量时遇到过订单页 500、页面元素找不到、ChromeDriver 超时。这些是测试代码和练习站自己的问题，已经在代码里处理掉，没有写进缺陷单：

- 订单页模板里 `order.items` 和字典的 `items()` 方法重名，订单明细渲染报 500。
- 页面跳转后没等 URL 变化就读列表，读到的是上一个页面。
- 用例之间共用浏览器，登录态和购物车串到下一条。
- Flask 服务的日志输出到管道没人读，请求多了以后服务端卡住。
