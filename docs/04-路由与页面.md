# 路由与页面

## 路由总表

| 方法 | 路径 | 模板/返回 | 说明 |
| --- | --- | --- | --- |
| GET | `/` | `index.html` | 首页，`q` 参数搜索 |
| GET | `/search` | 302 | 跳转到 `/?q=` |
| GET | `/api/health` | JSON | 健康检查，返回商品数、订单数、版本 |
| GET | `/dev/reset` | JSON | 仅本机可用的演示数据重置 |
| GET/POST | `/login` | `login.html` / 302 | 登录，支持 `next` |
| GET | `/logout` | 302 | 退出并清空会话 |
| GET | `/product/<int:pid>` | `product.html` | 商品详情 |
| GET | `/cart` | `cart.html` | 购物车 |
| POST | `/cart/add/<int:pid>` | 302 | 加购，校验库存 |
| POST | `/cart/update/<int:pid>` | 302 | 改数量，校验库存 |
| POST | `/cart/remove/<int:pid>` | 302 | 删除 |
| GET/POST | `/checkout` | `checkout.html` / 302 | 结算、创建订单 |
| POST | `/checkout/coupon` | 302 | 应用优惠券 |
| POST | `/checkout/coupon/clear` | 302 | 清除优惠券 |
| GET | `/order/<order_no>` | `order.html` | 订单详情 |
| POST | `/order/<order_no>/cancel` | 302 | 取消待支付订单 |
| POST | `/order/<order_no>/refund` | 302 | 申请退款 |
| POST | `/order/<order_no>/complete` | 302 | 确认收货 |
| GET/POST | `/pay/<order_no>` | `pay.html` / 302 | 模拟支付 |
| GET | `/admin` | `admin.html` | 管理后台，`?status=` 筛选 |
| POST | `/admin/orders/<order_no>/<action>` | 302 | 发货、完成、退款、取消 |
| POST | `/admin/products/<pid>/stock` | 302 | 调整库存 |
| POST | `/admin/coupons` | 302 | 创建优惠券 |
| POST | `/admin/users/<id>/toggle` | 302 | 启用/停用用户 |

## 页面说明

### 首页 `/`

- 读取 `q` 参数，空则返回全部上架商品；
- 按商品名和品牌匹配，SQL 使用 `LIKE`，大小写不敏感；
- 渲染商品卡片：品牌、名称、价格、库存；
- 库存为 0 时按钮禁用；库存 <= 3 时显示低库存提示；
- 没有结果时显示“没有找到相关商品”。

### 登录 `/login`

字段：`email`、`password`、`next`。

校验顺序：

1. 邮箱为空：提示“请输入邮箱”；
2. 密码为空：提示“请输入密码”；
3. 同一 IP + 邮箱 10 分钟内失败 10 次：提示限流；
4. 账号不存在或密码不对：提示“邮箱或密码错误”；
5. `active=0`：提示“账号已被停用”；
6. 成功：写入 Session，保留购物车，跳回 `next` 或首页。

### 商品详情 `/product/<pid>`

- 商品不存在返回 404；
- 显示名称、品牌、价格、库存、描述；
- 数量输入框最小 1，库存不足时禁止加购；
- 加购提交到 `/cart/add/<pid>`。

### 购物车 `/cart`

- 从 Session 读购物车；
- 每行显示商品、单价、数量、小计；
- 数量表单提交到 `/cart/update/<pid>`，超过库存会提示；
- 删除按钮提交到 `/cart/remove/<pid>`；
- 底部显示小计和“去结算”。

### 结算 `/checkout`

- 未登录重定向 `/login?next=/checkout`；
- 购物车为空重定向购物车；
- 购物车存在超库存行时重定向购物车并提示；
- GET 显示商品明细、VIP 折扣、优惠券、总价和收货表单；
- POST 校验收货人、手机号、地址；
- 提交后进入事务：检查并扣减库存、写订单、写明细、写状态流水、核销优惠券；
- 成功清空购物车和优惠券，跳订单详情。

收货字段：

| 字段 | 规则 |
| --- | --- |
| `receiver` | 至少 2 个字 |
| `phone` | `^1[3-9]\d{9}$` |
| `address` | 至少 5 个字 |

### 订单详情 `/order/<order_no>`

- 未登录跳登录；
- 订单不存在 404；
- 不是自己的订单 403（管理员可查看）；
- 显示订单号、状态、收货信息、商品明细、金额；
- 按状态显示支付、取消、退款申请、确认收货入口；
- 显示 `order_status_logs` 生成的时间线。

### 支付 `/pay/<order_no>`

- 未登录跳登录；
- 订单不存在 404；
- 不是自己的订单 403；
- 已支付：显示“该订单已支付”，不扣库存；
- 非待支付：显示当前状态，不允许支付；
- GET 显示支付方式；
- POST 校验 `method` 是否在 `alipay`、`wechat`、`card`；
- 成功写 `status=paid`、`payment_method`、`paid_at` 和状态流水，跳订单详情。

### 管理后台 `/admin`

- 仅 `role=admin` 可访问；
- 统计卡片：订单总数、成交金额、活跃用户、在售商品、待支付、退款审核；
- 订单列表支持按状态筛选；
- 订单操作：
  - `pending` → 取消；
  - `paid` → 发货 / 退款；
  - `shipped` → 完成 / 退款；
  - `refunding` → 同意退款；
- 商品库存可直接调整；
- 优惠券可新建；
- 用户可启用/停用，管理员账号不可停用。

## 模板继承

```text
base.html
├── index.html
├── login.html
├── product.html
├── cart.html
├── checkout.html
├── order.html
├── pay.html
├── admin.html
└── error.html
```

`base.html` 提供：

- 顶部导航：首页、购物车、登录/退出、管理后台；
- `cart_count()`：购物车总数量；
- `current_user()`：当前登录用户；
- `csrf_token()`：表单 CSRF Token；
- `flash` 消息区域；
- footer。

## 静态资源

- `shop/static/style.css`：响应式页面样式；
- 没有独立 JS 文件，数量选择和删除都用表单提交；
- 页面截图在 `docs/images/`，README 直接引用。
