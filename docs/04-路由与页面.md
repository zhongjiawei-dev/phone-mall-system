# 路由与页面

## 路由总表

| 方法 | 路径 | 模板/返回 | 说明 |
| --- | --- | --- | --- |
| GET | `/` | `index.html` | 首页，`q` 参数搜索 |
| GET | `/search` | 302 | 跳转到 `/?q=` |
| GET | `/api/health` | JSON | 健康检查 |
| GET | `/dev/reset` | JSON | 重置商品、订单、会话 |
| GET/POST | `/login` | `login.html` / 302 | 登录 |
| GET | `/logout` | 302 | 退出，清 session |
| GET | `/product/<int:pid>` | `product.html` | 商品详情 |
| GET | `/cart` | `cart.html` | 购物车 |
| POST | `/cart/add/<int:pid>` | 302 | 加购 |
| POST | `/cart/update/<int:pid>` | 302 | 改数量 |
| POST | `/cart/remove/<int:pid>` | 302 | 删除 |
| GET/POST | `/checkout` | `checkout.html` / 302 | 结算 |
| GET | `/order/<order_no>` | `order.html` | 订单详情 |
| GET/POST | `/pay/<order_no>` | `pay.html` / 302 | 支付 |

## 页面说明

### 首页 `/`

- 读取 `q` 参数，空则返回全部商品；
- 有 `q` 时按商品名和品牌做小写包含匹配；
- 渲染商品卡片：名称、品牌、价格、库存；
- 没有结果时显示“没有找到相关商品”；
- 导航栏显示购物车数量。

### 登录 `/login`

表单字段：`email`、`password`。

校验顺序：

1. 邮箱为空：提示“请输入邮箱”；
2. 密码为空：提示“请输入密码”；
3. 账号不存在或密码不对：提示“邮箱或密码错误”；
4. `active=False`：提示“账号已被停用”；
5. 成功：`session["email"] = email`，跳转首页。

### 商品详情 `/product/<pid>`

- 商品不存在返回 404；
- 显示名称、品牌、价格、库存、描述；
- 数量输入框，最小 1；
- 加购按钮提交到 `/cart/add/<pid>`。

### 购物车 `/cart`

- 从 session 读购物车；
- 每行显示名称、单价、数量、小计；
- 数量表单提交到 `/cart/update/<pid>`；
- 删除按钮提交到 `/cart/remove/<pid>`；
- 底部显示小计和“去结算”。

### 结算 `/checkout`

- 未登录重定向 `/login?next=/checkout`；
- 购物车为空重定向购物车；
- GET 显示商品明细、折扣、总价和收货表单；
- POST 校验收货人、手机号、地址；
- 校验失败用 `flash` 显示错误，保留页面；
- 成功生成订单、清空购物车、跳订单详情。

收货字段：

| 字段 | 规则 |
| --- | --- |
| `receiver` | 至少 2 个字 |
| `phone` | `^1[3-9]\d{9}$` |
| `address` | 至少 5 个字 |

### 订单详情 `/order/<order_no>`

- 未登录跳登录；
- 订单不存在 404；
- 订单不属于当前用户 403；
- 显示订单号、状态、收货信息、商品明细、金额；
- `pending` 显示“去支付”，`paid` 显示支付方式。

### 支付 `/pay/<order_no>`

- 未登录跳登录；
- 订单不存在 404；
- 不是自己的订单 403；
- 已支付：提示“订单已支付，不用重复付款”；
- GET 显示支付方式；
- POST 校验 `method` 是否在 `alipay`、`wechat`、`card`；
- 成功：状态改 `paid`，写 `payment_method`、`paid_at`，扣库存，跳订单详情。

## 模板继承

```
base.html
├── index.html
├── login.html
├── product.html
├── cart.html
├── checkout.html
├── order.html
└── pay.html
```

`base.html` 提供：

- 顶部导航：首页、购物车、登录/退出；
- `cart_count()`：购物车总数量；
- `current_user()`：当前登录用户；
- `flash` 消息区域；
- footer。

## 静态资源

- `shop/static/style.css`：页面样式；
- 没有独立 JS 文件，数量选择和删除都用表单提交；
- 页面截图在 `docs/images/`，README 直接引用。
