# 部署与运行

## 环境

- Python 3.10+
- Flask 3
- 浏览器访问 `http://127.0.0.1:9500`
- SQLite 由 Python 标准库提供，不需要额外安装数据库服务

安装依赖：

```bash
pip install -r requirements.txt
```

## 启动

```bash
python shop/app.py --port 9500
```

参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--port` | 9500 | 监听端口 |

启动后打开 `http://127.0.0.1:9500`。

## 数据库

默认数据库文件：

```text
shop/data/shop.db
```

首次启动自动执行 `shop/schema.sql` 建表，并写入演示用户、商品、优惠券。数据库文件和 WAL 文件已在 `.gitignore` 中排除。

通过环境变量指定路径：

```bash
SHOP_DB=/tmp/shop.db python shop/app.py --port 9500
```

## 健康检查

```bash
curl http://127.0.0.1:9500/api/health
```

返回：

```json
{"orders":0,"products":8,"status":"up","version":"1.5"}
```

`orders` 是当前订单数，`products` 是商品数。

## 重置数据

```bash
curl http://127.0.0.1:9500/dev/reset
```

会恢复 8 款手机的库存、清空订单、状态流水、优惠券核销记录和当前会话。该接口仅允许本机访问，生产环境应删除或加管理员权限。

## 自测

安装自测依赖：

```bash
pip install -r requirements-dev.txt
```

确保本机有 Chrome / Chromium 与匹配的 ChromeDriver，默认路径：

```text
/usr/local/bin/chromium
/usr/local/bin/chromedriver
```

也可以用环境变量指定：

```bash
CHROME_BIN=/usr/bin/google-chrome CHROMEDRIVER=/usr/bin/chromedriver pytest
```

跑全部：

```bash
pytest
```

只跑业务规则（不启动浏览器）：

```bash
pytest tests/test_business.py
```

自测脚本会自动选空闲端口启动 Flask 服务，跑完关闭；每条 UI 用例前访问 `/dev/reset` 和 `/logout` 重置状态。最近一次完整自测：`54 passed`。

## GitHub Actions

`.github/workflows/ui-tests.yml` 在每次 push 时：

1. 安装 Python 依赖；
2. 用 `browser-actions/setup-chrome` 安装稳定版 Chrome 和匹配的 ChromeDriver；
3. 启动 Flask 服务；
4. 执行 `pytest`；
5. 上传 Allure 结果和失败截图。

## 生产部署

当前应用可以直接用 Gunicorn 启动：

```bash
gunicorn -w 2 -b 0.0.0.0:9500 'shop.app:app'
```

注意事项：

- 生产必须设置随机 `SHOP_SECRET_KEY`；
- 多 worker 共享同一个 SQLite 文件只适合轻量场景，写入并发高时建议换 MySQL/PostgreSQL；
- 多实例部署时 Session 应改为 Redis 或数据库存储；
- 开启 HTTPS 后设置 `SHOP_COOKIE_SECURE=1`；
- `/dev/reset` 上线前应关闭或限制为管理员操作。

## 常见问题

**端口被占用**

换端口：`python shop/app.py --port 9501`。

**页面样式没加载**

确认 `shop/static/style.css` 存在。Flask 的静态目录默认是 `shop/static`。

**数据库锁住或数据异常**

停止服务后删除 `shop/data/shop.db`、`shop.db-wal`、`shop.db-shm`，重新启动会按 `schema.sql` 建表并写入种子数据。

**支付后库存没变**

V1.5 改为下单即锁库存，支付不再重复扣减；取消/退款才会释放库存。检查订单状态和 `stock_restored` 字段。

**自测启动不了浏览器**

确认 `CHROME_BIN` 和 `CHROMEDRIVER` 指向真实文件，版本要匹配。CI 里由 setup-chrome 自动处理。
