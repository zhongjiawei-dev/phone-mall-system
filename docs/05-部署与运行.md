# 部署与运行

## 环境

- Python 3.12（3.10+ 应该也可以）
- Flask 3
- 浏览器访问 `http://127.0.0.1:9500`

安装依赖：

```bash
pip install -r requirements.txt
```

## 启动

```bash
python shop/app.py --port 9500
```

参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--port` | 9500 | 监听端口 |

启动后打开 `http://127.0.0.1:9500`。

## 健康检查

```bash
curl http://127.0.0.1:9500/api/health
```

返回：

```json
{"orders":0,"products":8,"status":"up"}
```

`orders` 是当前订单数，`products` 是商品数。

## 重置数据

```bash
curl http://127.0.0.1:9500/dev/reset
```

会恢复 8 款手机的库存、清空订单、清空当前会话。这个接口只用于本地开发，生产环境应该删掉或加权限。

## 自测

安装自测依赖：

```bash
pip install -r requirements.txt
```

确保本机有 Chromium 和 ChromeDriver，默认路径：

```
/usr/local/bin/chromium
/usr/local/bin/chromedriver
```

也可以用环境变量指定：

```bash
CHROME_BIN=/usr/bin/google-chrome CHROMEDRIVER=/usr/bin/chromedriver pytest
```

跑全部：

```bash
pytest
```

只跑冒烟：

```bash
pytest -m smoke
```

自测脚本会自动选一个空闲端口启动 Flask 服务，跑完关闭；每条用例前访问 `/dev/reset` 和 `/logout` 重置状态。

## GitHub Actions

`.github/workflows/ui-tests.yml` 在每次 push 时：

1. 安装 Python 依赖；
2. 用 `browser-actions/setup-chrome` 安装稳定版 Chrome 和匹配的 ChromeDriver；
3. 启动 Flask 服务；
4. 执行 `pytest`；
5. 上传 Allure 结果和失败截图。

## 生产部署

当前版本用 Flask 开发服务器，生产环境建议：

```bash
gunicorn -w 1 -b 0.0.0.0:9500 'shop.app:app'
```

只能开 1 个 worker，因为商品、订单和库存在进程内存里；多 worker 会各存一份，库存和订单会不一致。要上多 worker，先把商品、订单、库存落到 MySQL，并把购物车换成 Redis 或数据库。

## 常见问题

**端口被占用**

换端口：`python shop/app.py --port 9501`。

**页面样式没加载**

确认 `shop/static/style.css` 存在，Flask 的静态目录默认是 `shop/static`。

**支付后库存没变**

检查订单状态是否 `pending`，支付方式是否在 `alipay`、`wechat`、`card` 里；已支付订单不会重复扣库存。

**自测启动不了浏览器**

确认 `CHROME_BIN` 和 `CHROMEDRIVER` 指向真实文件，版本要匹配。CI 里由 setup-chrome 自动处理。
